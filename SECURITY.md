# Security Policy

## Supported versions

Security fixes are intended for the current version on the `main` branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues or pull requests.

Use [GitHub's private vulnerability reporting form](https://github.com/Aaqibhafeezkhan/GameVault/security/advisories/new) if it is enabled for this repository. If private reporting is unavailable, contact the maintainer privately through the contact options on the [maintainer's GitHub profile](https://github.com/Aaqibhafeezkhan).

Include a description of the issue, its potential impact, and steps to reproduce it where safe to do so. Please allow time for the maintainer to investigate before making details public.

## Response

The maintainer will review the report, work to understand its impact, and coordinate a fix or mitigation before public disclosure where possible.
